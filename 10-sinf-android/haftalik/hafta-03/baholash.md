# 10-sinf (Advanced Android): 3-hafta baholash qaydnomasi

**Mavzular:**
1. Git bilan versiya nazorati asoslari: Gitning vazifasi, 3 holat (Working Dir, Staging Area, Repo), `git init`, `add`, `commit`, `log`, `.gitignore`
2. Git bilan ishlash amaliyoti: `git diff`, `git branch`, `switch`, `merge`, Merge Conflicts va ularni hal etish, `git stash`, `git revert`
3. GitHub’da loyihalar yaratish va boshqarish: Remote repozitoriy, `push`, `pull`, Public vs Private, `README.md`, Issues, Android Studio integratsiyasi

## Mentor qaydlari va tahlil

- **Darsdagi asosiy qiyinchiliklar:** O'quvchilar boshida `git commit` qilishdan oldin `git add` qilishni unutishadi yoki commit xabariga bir so'z yozish bilan cheklanishadi. Ularga professional jamoalarda commit xabarlari qoidasi qat'iy ekanini uqtirish zarur.
- **Konfliktlardan qo'rqmaslik:** Ko'pchilik o'quvchilar `CONFLICT` so'zini ko'rganda vahimaga tushadi. Konflikt bu dasturiy buzilish emas, balki tabiiy jarayon ekani va uni har bir dasturchi har kuni bir necha bor yechishi kerakligini jonli misollarda ko'rsatib bering.
