# 10-sinf (Advanced Android): 4-hafta baholash qaydnomasi

**Mavzular:**
1. GitLab va Bitbucket'da jamoaviy ish jarayonlari: platformalar, klonlash, Group va Team, access va roles, Issue tracker va Kanban, Merge Request, Code Review, pipeline
2. Branch, Merge va Pull Request jarayonlari: feature branching, `checkout -b`, `merge`, konfliktlarni hal qilish, PR va Code Review
3. Continuous Integration (CI/CD) tushunchasi: CI, Delivery va Deployment, pipeline, GitHub Actions (YAML), Secrets

## Mentor qaydlari va tahlil

- **Kutilayotgan qiyinchiliklar:** konflikt belgilarini o'qish (qaysi qism qaysi branchniki), YAML'da indent xatolari, MR va PR atamalari aralashishi.
- **Eslatma:** hujjatda GitLab/Bitbucket menyulari va rollar nomlari bo'yicha tafsilot kam; bu qismlarda umumiy tamoyillarga tayaning.
- **Keyingi haftaga ko'prik:** 5-hafta build.gradle faylining tuzilmasi va modullararo bog'lanishiga qaytadi.
