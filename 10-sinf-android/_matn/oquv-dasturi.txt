1. DASTURDA QOʻLLANILGAN TAYANCH ATAMALAR           
Kasb - Advanced Android dasturlash bo‘yicha nazariy bilimlar, amaliy ko‘nikma va malakalarni egallab, mobil ilovalarni ishlab chiqish, sinovdan o‘tkazish va nashr qilishga qodir mutaxassislik faoliyatini amalga oshirish uchun zarur tayyorgarlikka ega bo‘lgan mehnat faoliyati turi.
Ko‘nikma - Android Studio, IntelliJ IDEA, Java yoki Kotlin tillarida dastur yozish, interfeys yaratish (XML yoki Jetpack Compose orqali), ma’lumotlar bazasi (SQLite, Firebase Firestore) bilan ishlash, ilovani testlash va nashr qilishni o‘z ichiga olgan amaliy faoliyatni bajarish qobiliyati.
Bilim - Android operatsion tizimi, Java/Kotlin dasturlash tillari sintaksisi, ma’lumotlar tuzilmalari, foydalanuvchi interfeysi (UI) elementlari, tarmoq texnologiyalari (Retrofit, Volley, OkHttp) hamda Firebase xizmatlari haqidagi nazariy ma’lumotlarni o‘zlashtirish va tushuntirish imkoniyati.
Kompetensiya - Dasturchilik jarayonida olingan bilim va ko‘nikmalarni amaliy loyihalarda qo‘llash, muammoli vaziyatlarni tahlil qilish, texnik yechimlarni ishlab chiqish hamda dasturiy mahsulotni foydalanuvchiga qulay shaklda yaratish qobiliyati.
Kasbiy faoliyat sohasi - Mobil dasturlash, axborot texnologiyalari, dasturiy ta’minot ishlab chiqish, foydalanuvchi interfeysi loyihalash va ma’lumotlar bazasi bilan ishlash yo‘nalishlarini qamrab oladi.
Kasbiy faoliyat obyekti - Mobil ilovalar, foydalanuvchi interfeyslari, ma’lumotlar bazalari, tarmoq orqali ma’lumot almashish tizimlari, dasturiy kod va foydalanuvchi tajribasi (UX).
Kasbiy faoliyat turi - Android platformasi uchun dasturiy ta’minot yaratish, texnik sinovdan o‘tkazish, dizayn va texnik hujjatlarni ishlab chiqish, Firebase va Google Play Console orqali ilovani joylashtirish faoliyatlari majmui.
O‘quv rejasi - “Android dasturlash” fani bo‘yicha o‘quv mashg‘ulotlari tarkibi, ularni o‘rganish ketma-ketligi, amaliy mashg‘ulotlar, oraliq va yakuniy nazorat ishlarining umumiy hajmi va mazmunini belgilovchi hujjat.
O‘quv amaliyoti - Android Studio muhitida loyihalar yaratish, Java yoki Kotlin dasturlari yozish, XML interfeys chizish, ma’lumotlar bazasi bilan ishlash, ilovani testlash va xatoliklarni tuzatish jarayonlari.
Kasbga tayyorlash o‘quv kursi - 9-sinf o‘quvchilari uchun mo‘ljallangan, mobil dasturlashning zamonaviy vositalarini (Android Studio, Firebase, Retrofit, Firestore, Google Play Console) o‘rgatuvchi amaliy yo‘nalishdagi darslar majmuasi.
Ta’lim dasturi - “Android dasturlash” fanining maqsadi, mazmuni, o‘quv natijalari, tashkiliy-pedagogik shart-sharoitlari hamda nazorat va baholash tartibini belgilovchi me’yoriy-uslubiy hujjat.
Android Studio muhiti - Android ilovalarini ishlab chiqish uchun mo‘ljallangan integratsiyalashgan dasturlash muhiti (IDE) bo‘lib, u Java, Kotlin, XML, Compose, Gradle va Emulator vositalarini o‘z ichiga oladi.
Gradle - Android loyihalarini build, sinxronizatsiya va kompilyatsiya qilish tizimi.
GitHub / GitLab / Bitbucket - onlayn platformalar bo‘lib, jamoaviy dastur ishlab chiqishni tashkil etadi.
XML (Extensible Markup Language) - Android ilovalarida foydalanuvchi interfeysining (UI) tuzilmasini yaratish uchun ishlatiladigan belgilash tili.
Retrofit, Volley, OkHttp - Internet orqali ma’lumot almashish (API so‘rovlar) uchun qo‘llaniladigan Android kutubxonalari.
Firebase - Google tomonidan yaratilgan mobil platforma bo‘lib, u autentifikatsiya (login/ro‘yxatdan o‘tish), ma’lumotlar bazasi (Firestore, Realtime DB), bildirishnomalar va tahlil xizmatlarini taqdim etadi.
MVVM (Model -View-ViewModel) - ilovaning mantiqiy arxitekturasini qatlamlarga ajratish modeli.
MVP (Model-View-Presenter) - foydalanuvchi interfeysi va biznes mantiqni ajratish tamoyiliga asoslangan model.
MVI (Model-View-Intent) - foydalanuvchi harakatlarini voqealar (intent) orqali boshqaruvchi arxitektura.
Google Play Console - Dasturchilar uchun yaratilgan xizmat bo‘lib, unda Android ilovalari sinovdan o‘tkazilib, Play Market’da nashr qilinadi.
Android Emulator - Android qurilmasining virtual nusxasi bo‘lib, dasturchilarga ilovalarni kompyuterda testlash imkonini beradi.

5. ADVANCED ANDROID DASTURLASH KASBI OʻQUV DASTURI
I-BOB. Android loyihalarini boshqarish va versiya nazorati tizimlari
Gradle konfiguratsiyasi va build variantlari: Gradle fayllarining tuzilmasi (build.gradle, settings.gradle), dependency’larni e’lon qilish, build variantlar (debug, release) yaratish, buildType va flavor’lar bilan ishlash, Gradle skriptlarini avtomatlashtirish. Dependency management va versiyalar bilan ishlash: Kutubxona versiyalarini boshqarish, implementation va api farqlari, versiyalarni yangilash strategiyasi, dependency conflicts yechimi, BOM (Bill of Materials) orqali boshqaruv. ProGuard va R8 yordamida kodni optimallashtirish: Kodni minimallashtirish (minifyEnabled), ProGuard qoidalari, R8 optimizatsiyasi, mapping fayllarni yaratish va tahlil qilish, ilova xavfsizligini oshirish. Git bilan versiya nazorati asoslari: Git repository yaratish, commit, push, pull amallari, .gitignore va .gitattributes fayllari, git log orqali tarixni tahlil qilish. GitHub’da loyihalar yaratish va boshqarish: Repository yaratish va ulashish, README fayl yaratish, issues va branches  bilan ishlash, pull request jarayonlari, GitHub Actions bilan CI/CD. GitLab va Bitbucket’da jamoaviy ish jarayonlari: Loyihani klonlash, jamoaviy branch strategiyasi, merge request jarayoni, access va roles boshqaruvi, pipeline sozlash. Branch, Merge va Pull Request jarayonlari: Branch turlari (main, develop, feature), merge usullari (fast-forward, squash),  konfliklarni yechish, pull request yaratish, kodni review qilish. Continuous Integration (CI/CD) tushunchasi: CI/CD ishlash prinsipi, build va test avtomatlashtirish, GitHub Actions va GitLab CI misollari, pipeline yaratish, deploy jarayonini nazorat qilish.
II-BOB. Android arxitekturasi va dastur tuzilmasi
MVVM arxitekturasi asoslari: Model-View-ViewModel tushunchasi, data binding, ViewModel lifecycle, repository bilan aloqasi,  UI’dan mustaqil logika tashkil etish. MVI (Model-View-Intent) yondashuvi: Intentlar orqali foydalanuvchi harakatlarini boshqarish, state’larni kuzatish, reducer funksiyasi, UI reaktivligi, Compose bilan MVI integratsiyasi. MVP (Model-View-Presenter) modeli: View va Presenter o‘rtasidagi aloqa, interfeyslar orqali bog‘lash, testlash qulayliklari,  mas’uliyatni ajratish, eski loyihalar uchun qo‘llanishi. ViewModel va LiveData bilan ishlash: LiveData kuzatuvchilari  (observe), ViewModelProvider orqali chaqirish, MutableLiveData va StateFlow farqi, lifecycle aware komponentlar, foydalanuvchi holatini saqlash. StateFlow va SharedFlow oqimlarini boshqarish: Flow asoslari, StateFlow bilan real vaqt oqimlari, SharedFlow yordamida hodisalarni qayta ishlash, collectAsState bilan UI yangilash, error handling oqimlari. Repository pattern va ma’lumot oqimini loyihalash: Repository qatlamining vazifasi, ma’lumot manbalarini ajratish (local va remote),  interface orqali implementatsiya, testlanadigan arxitektura, data caching. Dependency Injection (Dagger, Hilt, Koin): DI tushunchasi, Dagger komponentlari, Hilt modullari, Koin soddalashtirilgan sintaksisi,  servislar orasidagi bog‘liqlikni kamaytirish. Clean Architecture tamoyillari: Domain, data va presentation  qatlamlari, interfeyslar orqali mustaqillik, entity va use-case’lar,  SOLID prinsiplari, kodni kengaytirish imkoniyati. Amaliy mashg‘ulot – “Smart Finance App: MVVM asosida hisob-kitob moduli”: ViewModel orqali hisoblash logikasi, Room’dan ma’lumot olish, Compose UI’da natija chiqarish, foydalanuvchi interfeysini holatga bog‘lash, oraliq nazorat ishlanmasi.
III-BOB. Ma’lumotlar bazalari va sinxronlash tizimlari
SQLite bilan ma’lumot saqlash: SQL asoslari, jadval yaratish (CREATE TABLE), CRUD amallari, SQLiteOpenHelper sinfi, local database bilan ishlash. Room Database orqali ORM ishlatish: Entity, DAO va Database annotatsiyalari, LiveData bilan ma’lumot kuzatish, @Insert,  @Update, @Delete amallari, coroutine asosida so‘rovlar. Realm Database bilan real vaqtli ma’lumot almashish: Realm o‘rnatish va konfiguratsiya, obyektlar asosida saqlash, kuzatuvchilar  bilan ishlash, tezkor sinxronizatsiya, mobil cache mexanizmi. Firebase Firestore bilan ma’lumot sinxronligi: Real-time database va  Firestore farqi, collection-document tuzilmasi, addSnapshotListener, ma’lumot o‘zgarishini onlayn kuzatish, xavfsizlik qoidalari. Repository qatlamida ma’lumotlar oqimi: Local va remote data source integratsiyasi, data refresh strategiyasi, suspend fun orqali  oqim boshqaruvi, ViewModel’da ma’lumotni birlashtirish, error handling. Offline/online sinxronizatsiya mexanizmlari: Network monitoring, cache priority modeli, offline saqlash va qayta yuborish, ConnectivityManager  bilan aloqani aniqlash, Firestore offline mode. JSON formatida ma’lumot almashish: JSON tuzilmasi (object, array),  Gson va Moshi bilan serialization/deserialization, model  sinflarni moslashtirish, nested obyektlar, JSON xatolarni tahlil qilish. Data caching va Local Storage strategiyalari: Cache qatlamlari, SharedPreferences va fayl-based cache, Room caching,  retrofit response cache, xotira va tezlik muvozanatini saqlash. Amaliy mashg‘ulot – “Smart Finance App: Offline va Cloud sinxronizatsiya”: Room + Firestore integratsiyasi, foydalanuvchi balansini avtomatik yangilash, internet yo‘q paytda ma’lumotni saqlash, qayta ulanish mexanizmi.
IV-BOB. Tarmoq va API integratsiyasi
Retrofit bilan RESTful API chaqirish: Retrofit sozlash, interfeysda endpoint’lar, @GET va @POST so‘rovlar, coroutine bilan  asinxron ishlash, JSON javoblarini modelga o‘tkazish. Volley orqali HTTP so‘rovlarni yuborish: RequestQueue va JsonObjectRequest, onResponse va onErrorResponse ishlov  berish, progress ko‘rsatkichlari, caching funksiyasi, API tezkorligi. OkHttp bilan tarmoq nazorati va interceptorlar: Logging interceptor, header qo‘shish, custom interceptor, tarmoq xatoliklarini tahlil qilish, offline cache. API javoblarini JSON formatida tahlil qilish (Gson, Moshi): Gson  builder, @SerializedName, nested JSON obyektlari, parsing  jarayonida xatolarni ushlash, dynamic key bilan ishlash. Autentifikatsiya: OAuth2.0 va Token almashuvi: Access va refresh tokenlar, API kalitlarini xavfsiz saqlash, authorization  header yaratish, token yangilash, foydalanuvchi sessiyasi nazorati. Error handling va retry strategiyalari: Tarmoq xatoliklarini  aniqlash (IOException, HttpException), retry mexanizmi, exponential  backoff, foydalanuvchi xabar berish tizimi, global error handler. Retrofit + Room integratsiyasi (API cache): Remote ma’lumotni saqlash, Room orqali lokal qayta ishlash, UI’da real vaqt yangilanishi,  API’dan ma’lumotlarni sinxronlashtirish, offline-first strategiya. Amaliy mashg‘ulot – “Smart Finance App: Valyuta va API integratsiyasi”: API’dan kurslarni olish, real vaqt yangilanishi, foydalanuvchi interfeysida valyuta hisoblash, xatolarni boshqarish, oraliq nazorat. API xavfsizligi va versiyalash tamoyillari: HTTPS talablari, API key’larni yashirish, versiyalarni (v1, v2) boshqarish, backward compatibility, autentifikatsiya qatlamini himoyalash.
V-BOB. Jetpack Compose va zamonaviy UI dizayn
State Management: remember va mutableStateOf, hoisting konsepti, Compose’da holatni boshqarish, StateFlow integratsiyasi, UI qayta chizilish jarayoni. Layoutlar: Column, Row, Box joylashuvi, LazyColumn va LazyRow ro‘yxatlari, Modifier parametrlar, alignment, padding va spacing. Material3 komponentlari: Temalar yaratish, rang palitralari, Typography bilan ishlash, Card va Button komponentlari, dark/light rejimlar. Navigation Component va multi-screen arxitekturasi: NavController, composable ekranlar o‘rtasida o‘tish, argument uzatish,  BottomNavigation integratsiyasi, back-stack boshqaruvi. Rasm, ikon va animatsiyalar bilan ishlash: Image va Icon  composable’lar, painterResource, animatsiyalar (animateDp, animateColor),  Lottie integratsiyasi, UI dinamizmini oshirish. Custom Composable elementlar: Reusable UI komponentlar yaratish, slot API ishlatish, parametrlar bilan moslashuvchan elementlar, styling va theming, preview test. Gesture Detection va foydalanuvchi interaktivligi: Tap, swipe, drag, long-press hodisalarini ushlash, pointerInput API, animatsiyalar bilan  bog‘lash, interaktiv elementlar yaratish, feedback. Adaptive UI va responsiv dizayn: ConstraintLayout va BoxWithConstraints, ekran o‘lchamiga moslashuv, tablet/TV dizayni, windowSizeClass, dynamic UI yaratish. UI testlash (Espresso, Compose Testing): Test case yozish, elementlarni onNodeWithText orqali aniqlash, UI xatti-harakatlarni tekshirish, performans testlari, CI bilan integratsiya.
VI-BOB. Firebase xizmatlari va ilova integratsiyasi
Firebase Authentication: Foydalanuvchini ro‘yxatdan o‘tkazish, login/logout funksiyalari, Email, Google, Facebook bilan autentifikatsiya,  token asosida sessiya boshqaruvi, xavfsizlik qoidalari. Firebase Firestore orqali ma’lumot almashish: Collection/document tuzilmasi, CRUD amallari, addSnapshotListener, offline rejimda ishlash, real-time yangilanish. Firebase Cloud Messaging (FCM): Push xabarnomalar yaratish, topic subscription, foydalanuvchi targeting, bildirishnomalarni  UI’da ko‘rsatish, foreground/background xatti-harakatlari. Firebase Storage bilan fayl yuklash: Rasm va hujjatlarni saqlash, fayl yuklab olish (downloadUrl), progress kuzatish, foydalanuvchi  profil rasmini o‘zgartirish, ruxsatlarni boshqarish. Firebase Remote Config va A/B Testing: Dynamic konfiguratsiyalar, parametrlarni masofadan yangilash, foydalanuvchilar uchun A/B test, natijalarni tahlil qilish, tajriba asosida interfeysni optimallashtirish. Firebase Analytics bilan ilova tahlili: Foydalanuvchi harakatlarini kuzatish, event yaratish, dashboard orqali tahlil, ilova samaradorligini baholash, foydalanuvchi segmentatsiyasi. Firebase Crashlytics bilan xatolarni kuzatish: Real-time crash loglar, stack trace tahlili, foydalanuvchi konteksti, crash alert, xatolarni kamaytirish strategiyasi. Smart Finance App – Foydalanuvchi tizimi va xabarnomalar: Auth + Firestore integratsiyasi, shaxsiy ma’lumotlar boshqaruvi, FCM xabarnomalarini yuborish, tahlil qilish, oraliq nazorat.
VII-BOB. Testlash, tarqatish va yakuniy loyiha
JUnit bilan unit testlar yozish: Test sinflar yaratish, @Test annotatsiyasi, assert funksiyalari, test jarayonlarini avtomatlashtirish, test log tahlili. Mockito bilan komponentlarni soxtalashtirish (mocking): Mock obyektlar yaratish, when va verify funksiyalari, testlarda real  ma’lumotlardan mustaqillik, dependency mocklash, test izolyatsiyasi. Espresso bilan UI testlarini avtomatlashtirish: UI elementlarini topish, foydalanuvchi harakatlarini simulyatsiya qilish, test ssenariylari  yozish, natijalarni tahlil qilish, CI integratsiyasi. Firebase Test Lab va real qurilmalarda sinov: Ilovani turli qurilmalarda sinash, crash monitoring, performance test, test natijalarini vizual tahlil, optimallashtirish takliflari. Test Coverage va Continuous Testing: Kod qamrovini o‘lchash, test hisobotlarini yaratish, CI’da testlarni avtomatik ishga tushirish, regressiya testlash, tahliliy metrikalar. Ilovani APK/AAB shaklida yaratish: Build variantlarini tayyorlash, ilovani sign qilish (keyStore), release variant yaratish,  AAB formatida eksport, versiya raqamlarini boshqarish. Google Play Console orqali ilovani nashr qilish: Developer account sozlash, metadata tayyorlash (ikon, tavsif, screenshot),  test kanallarini yaratish, beta va production nashr, yangilanishlarni joylashtirish. Versiya boshqaruvi va yangilanish jarayoni: Semantik versiyalash (1.0.0 → 1.1.0), changelog tayyorlash, foydalanuvchi bildirishnomalari, orqaga moslik, yakuniy loyiha himoyasi uchun tayyorgarlik.

7. ANDROIDDA SODDA O‘YINLAR YARATISH VA NAZORAT ISHI.
Android platformasida 2D formatdagi eng sodda o‘yinlarni yaratish orqali o‘quvchilarda dasturlashga qiziqish, mantiqiy fikrlash va ijodkorlikni rivojlantirish. Dars davomida Android Studio muhiti asosida o‘yin loyihasining tuzilishi, o‘yin oynasi (Game Screen) va bosh menyu (Main Menu) yaratish, o‘yinchi obyektini (character/player) chizish va harakatlantirish, fon rasmlari va oddiy animatsiyalarni qo‘llash ko‘rib chiqiladi. O‘yin jarayonini boshqarish uchun Timer/Handler/Coroutines yordamida o‘yin sikli (game loop) tashkil etish, sensor (touch) orqali boshqarish, to‘qnashuvlarni (collision) aniqlash, hisoblagichlar (score, vaqt, jonlar) bilan ishlash amaliy misollarda tushuntiriladi.
O‘quvchilar kichik loyihalar sifatida “Topni ushla”, “Obyektlardan qochish”, “Tap o‘yini” kabi sodda o‘yinlarni yaratadilar, unda asosiy UI elementlari, rasm va ovoz resurslari, oddiy animatsiya va o‘yin qoidalari bosqichma-bosqich joriy etiladi. O‘yin kodini optimallashtirish, xatolarni topish va tuzatish uchun Logcat va debugging vositalaridan foydalanish ko‘nikmalari mustahkamlanadi. Nazorat ishi doirasida o‘quvchi o‘qituvchi bergan texnik topshiriq asosida o‘zining sodda o‘yin loyihasini ishlab chiqadi, funksiyalarini namoyish etadi va qisqacha taqdimot qiladi; bunda g‘oya, texnik bajarilish, dizayn va o‘yin jarayonining barqaror ishlashi bo‘yicha baholanadi.

9. BAHOLASH MEZONLARI
	Oʻquvchilarning kasbga oid bilim, koʻnikma, malaka va kompetensiyalarini baholash va nazorat qilish maqsadida quyidagi nazorat turlari amalga oshiriladi:
joriy nazorat - soʻrovlar, bajarilgan loyiha ishlarini izohlash tarzida oʻquvchilarning bilimlari, koʻnikma va malakalari muntazam nazorat qilinadi.
oraliq nazorat - chorak tamom boʻlganda va oʻquv dasturining tegishli boʻlimi tugallangandan keyin oʻquvchilarning bilimlari, koʻnikma va malakalarini baholash uchun amalga oshiriladi. U amaliy, yozma nazorat ishi yoki testlar shaklida oʻtkaziladi. Ushbu nazoratda foydalaniladigan materiallar Advanced Android Dasturlash kasbi boʻyicha kasbiy taʼlim ustasi tomonidan tayyorlanadi. Oraliq nazorat har chorak yakunida o‘tkaziladi va nazorat ishlarining miqdori va mavzulari oʻquv dasturiga asoslangan rejada belgilanadi hamda muddati va shakli koʻrsatiladi.
yakuniy nazorat - oʻquv yili tamom boʻlgandan keyin ogʻzaki va amaliy ish koʻrinishida imtihon shaklida amalga oshiriladi. Uning asosida reyting aniqlanadi va oʻquvchini navbatdagi sinfga oʻtkazish toʻgʻrisida qaror qabul qilinadi. Yakuniy nazorat materiallari kasbiy taʼlim ustasi tomonidan oʻquv dasturi asosida tayyorlanadi va ularni amaliy fanlar uslubiy birlashmasi muhokamasidan oʻtkaziladi. Umumiy oʻrta taʼlim muassasalari bitiruvchilari uchun choraklik baholar asosida yillik baho, shuningdek, yakuniy nazoratda olingan baho va yillik baho asosida yakuniy baho aniqlanadi.
Kasbiy taʼlim yoʻnalishi boʻyicha yakuniy nazorat imtihonlarni oʻtkazish tartibi.
Kasbiy taʼlim yoʻnalishi boʻyicha oʻquv reja va dasturning barcha talablarini toʻliq bajargan bitiruvchiga maktab direktorining buyrugʻiga asosan amaliy yakuniy nazoratni topshirishga ruxsat beriladi.
Yakuniy nazorat oʻtkazish jadvali, u oʻtkaziladigan kunlar koʻrsatilgan holda, maktab direktori tomonidan tasdiqlanadi va yakuniy nazorat boshlanishidan kamida oʻn besh kun oldin taʼlim muassasasining oʻquvchilar koʻrishi mumkin boʻlgan joydagi eʼlonlar taxtasiga osib qoʻyish orqali oʻquvchilar xabardor etiladi.
Yakuniy nazorat amaliy topshiriq shaklida oʻtkaziladi. Bunda yakuniy nazorat savollari orqali bitta amaliy topshiriq beriladi.
Amaliy topshiriqlar oʻqitilgan mutaxassislik oʻquv dasturi asosida tuziladi va maktabning pedagogik kengashi tomonidan tasdiqlanadi hamda yakuniy nazorat boshlanishidan kamida oʻn besh kun oldin barcha oʻquvchilar koʻrishi mumkin boʻlgan joydagi eʼlonlar taxtasiga osib qoʻyish orqali oʻquvchilar eʼtiboriga yetkaziladi.
