# 10-sinf (DevOps): 3-hafta baholash qaydnomasi

**Mavzular:**
1. Git bilan ishlash (2-qism): Branchlar, merge, mojarolar (conflict resolution) va GitHub (push, pull, clone)
2. Kompyuter tarmoqlari asoslari: LAN/WAN, tarmoq uskunalari, OSI 7 qatlamli modeli va TCP/IP steki, enkapsulyatsiya
3. IP manzillash va tarmoq diagnostikasi: IPv4/IPv6, RFC 1918 xususiy tarmoqlar, Subnetting/CIDR, ping, traceroute, ss, curl

## Mentor qaydlari va tahlil

- **Darsdagi asosiy qiyinchiliklar:** O'quvchilar Git'da merge conflict chiqqanda mojaroli belgilarni (`<<<<<<<`, `=======`, `>>>>>>>`) qo'lda to'g'irlab, qayta `git add` va `git commit` qilish tartibini unutib qo'yishlari mumkin. Tarmoq mavzusida esa Subnetting (masalan, `/26` prefiksida nechta IP bo'lishi va tarmoq/broadcast manzillarini ajratish) qo'shimcha amaliy hisoblashni talab qiladi.
- **Iqtidorli o'quvchilar uchun:** GitHub Pull Request jarayonini sinfdoshlari bilan juftlikda sinab ko'rish yoki `curl -Iv` orqali HTTPS handshake va HTTP javob headerlarini to'liq tahlil qilish topshirig'i berilishi mumkin.
