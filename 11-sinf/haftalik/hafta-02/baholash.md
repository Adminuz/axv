## Hafta xulosasi va 3-haftaga ko'prik

**Bu hafta:** O'quvchi individual kod yozish doirasidan chiqib, professional jamoaviy muhandislik madaniyatini o'zlashtirdi: GitHub Flow, Conventional Commits, Pull Request arxitekturasi, merge konfliktlarini mustaqil yechish, konstruktiv Code Review va `main` tarmog'ini himoyalash.

**Keyingi hafta (3-hafta, 7–9 darslar):** Kod sifati va tizimli dasturlashning asosiy tamoyillari — **Clean Code va SOLID** (SRP, OCP, LSP, ISP, DIP). O'quvchi ushbu tamoyillarni o'zlashtirib, o'zining kelajakdagi loyihalarini arxitekturaviy jihatdan mukammal va kengaytiriladigan darajada qurishni o'rganadi.

**Mentor uchun keyingi dars oldidan tekshiruv:**
- O'quvchi Git terminal buyruqlarida adashmayaptimi (ayniqsa, branchlararo o'tish va rebase/merge)?
- GitHub da PR ochish va sharh qoldirish erkin qo'llanilayaptimi?
- OOP (Obyektga yo'naltirilgan dasturlash) asosiy tushunchalarini (klass, obyekt, vorislik, polimorfizm) eslaydimi? 3-hafta boshida OOP bo'yicha 5 daqiqalik qisqa savol-javob o'tkazish tavsiya etiladi.
