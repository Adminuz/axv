# 6-hafta: Uyga vazifa

**Fan:** Computer Science Foundation  
**Sinf:** 8-sinf  
**Hafta:** 6-hafta  
**Topshirish muddati:** Keyingi darsga qadar (7-hafta, 1-dars)

---

## Topshiriq 1: GitHub akkaunti va push · qiyin

1. GitHub'da (ota-ona bilan) akkaunt oching yoki mavjud akkauntda 2 bosqichli tekshiruvni yoqing; username'ingizni daftarga yozing.
2. `kundalik` nomli bo'sh repository yarating va loyihani push qiling.
3. Yana 2 ta yangi commit qilib push qiling; GitHub'dagi commitlar sahifasidan skrinshot oling yoki daftarga yozing.
4. Akkaunt ochish imkoni bo'lmasa: repo yaratish va push ketma-ketligini 6 qadamda daftarga yozing.

---

## Topshiriq 2: clone, pull va branch · o'rta

1. `kundalik` repo'ngizga README.md yozing: sarlavha, qisqa tavsif, 3 bandli ro'yxat va muallif (shaxsiy ma'lumotsiz). Commit va push qiling.
2. `yangi-sahifa` nomli branch yarating, unda fayl qo'shing va `main` ga merge qiling. `git log --oneline` natijasini daftarga yozing.
3. Do'stingiz yoki ustozingizning Public repo'sini clone qiling va ichidagi fayllar ro'yxatini yozing.
4. GitHub imkoni bo'lmasa: clone, pull, branch, merge buyruqlarini misol bilan daftarga yozing.

---

## Topshiriq 3: Zamonaviy IT yo'nalishlari · oson

1. Oltita yo'nalishning har biri uchun hayotdan bitta mahsulot misoli yozing.
2. Eng qiziq 2 ta yo'nalishni tanlang va sababini 2–3 gapda yozing.
3. Tanlangan yo'nalish uchun birinchi 3 qadamli reja tuzing (masalan, nimani o'rganish, qaysi vosita, qanday kichik loyiha).
4. Ota-onangiz yoki tanishingizdan IT sohasida ishlaydigan odam bo'lsa, undan ishi haqida 2 ta savol so'rang.

## Mentor uchun

**Tekshirish:**
- 16-dars: Push nimani yuboradi?? Javobi: Faqat commit qilinganlarni.
- 17-dars: README qaysi formatda?? Javobi: Markdown (.md).
- 18-dars: Etik xaker nima qiladi?? Javobi: Ruxsat bilan zaiflik topadi.

**Keng tarqalgan xatolar:**
- 16-dars: Push oldidan git commit qilishni unutish.
- 17-dars: clone dan keyin papkaga cd bilan kirishni unutish.
- 18-dars: AI javobiga tekshirmay ishonish.
