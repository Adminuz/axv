02

Slicing (Qirqib olish)

satr[boshlanish : tugash : qadam]

Slicing qoidalari va namunalari

Oraliqni olish

s = "Programmer"
print(s[0:4])   # Prog (4 kirmaydi!)
print(s[:4])    # Prog (boshidan)
print(s[3:])    # grammer (oxirigacha)

Qadam va teskari o'girish

s = "Backend"
print(s[::2])   # Bcen (2 qadam bilan)
print(s[::-1])  # dnekcaB (teskari!)
03

Asosiy string metodlari

Matnlarni qayta ishlash uchun rasmiy funksiyalar

Katta-kichik harflar metodlari

upper() va lower()

s = "Salom Dunyo"
print(s.upper())  # SALOM DUNYO
print(s.lower())  # salom dunyo

title() va capitalize()

s = "alisher navoiy"
print(s.title())       # Alisher Navoiy
print(s.capitalize())  # Alisher navoiy
