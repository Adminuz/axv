02

val va var: O'zgaruvchilar

O'zgarmaslik (Immutability) intizomi va xavfsiz kod

val vs var taqqoslovi

val (Value — O'zgarmas)

Bir marta qiymat oladi, keyin o'zgarmaydi (Read-only):

val pi = 3.14159
val ism = "Sanjar"
// pi = 3.14 -> XATOLIK!

Android'da 90% holatda val ishlatiladi!

var (Variable — O'zgaruvchan)

Dastur davomida qiymati o'zgarishi mumkin:

var ball = 70
ball = 85
ball = ball + 10  // 95

Faqat qiymati aniq o'zgaradigan holatlarda.

03

Ma’lumot turlari va String Templates

Int, Double, Boolean va qulay matn shablonlari

Asosiy ma'lumot turlari

Sonli turlar

  • Int — Butun sonlar: val yosh = 15
  • Double — Kasr sonlar: val narx = 19.99
  • Float — O'nlik son: val foiz = 4.5f

Matn va mantiqiy turlar

  • Boolean — true yoki false
  • Char — Bitta belgi: 'A'
  • String — Matn: "Android"

String Templates: $ belgisi

O'zgaruvchini ulash ($)

val ism = "Anvar"
val yosh = 15
println("Salom, mening ismim $ism, yoshim $yosh da.")

Hisob-kitoblarni kiritish (${ })

val a = 10
val b = 20
println("Yig'indi: ${a + b}")
// Yig'indi: 30

val > var
