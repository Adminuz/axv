01

List (Ro'yxat) tushunchasi

Tartiblangan va o'zgartirish mumkin bo'lgan universal to'plam

1-qism: List xususiyatlari.

List yaratish va elementni o'zgartirish

Yaratish va Indeks

mevalar = ["olma", "banan", "gilos"]
print(mevalar[0])   # olma
print(mevalar[-1])  # gilos

Mutable (O'zgaruvchan)

sonlar = [10, 20, 30]
sonlar[1] = 99
print(sonlar)  # [10, 99, 30]
Stringdan farqi: listda to'g'ridan-to'g'ri a[1] = 99 qilish mumkin.
02

Element qo'shish: append va insert

Ro'yxatni dinamik kengaytirish usullari

2-qism: Qo'shish metodlari.

append() vs insert()

append(qiymat)

Doim ro'yxatning eng oxiriga yangi element qo'shadi:

a = [1, 2]
a.append(3)
print(a)  # [1, 2, 3]

insert(indeks, qiymat)

Ko'rsatilgan indeksga element qo'yib, qolganlarini suradi:

a = [1, 2, 3]
a.insert(0, 0)
print(a)  # [0, 1, 2, 3]
append doim tez ishlaydi (O(1)), insert esa elementlarni surgani uchun resurs talab qiladi.
03

Element o'chirish: remove, pop va clear

Tozalash va kerakli elementni sug'urib olish

3-qism: O'chirish metodlari.

3 xil o'chirish usuli

remove(qiymat)

Qiymat bo'yicha birinchi uchraganini o'chiradi:

a = [1, 2, 2, 3]
a.remove(2)
# a → [1, 2, 3]

pop(indeks)

Indeksdagi elementni sug'urib qaytaradi:

a = [10, 20, 30]
x = a.pop(0)
# x=10, a=[20, 30]

clear()

Ro'yxatni butunlay bo'shatadi:

a = [1, 2, 3]
a.clear()
# a → []
pop() ning parametr berilmasa oxirgisini olishini eslatib o'ting.

Tezkor sinov: Natijani toping

Quyidagi kod natijasini taxmin qiling:

a = [1, 2, 2, 3]
a.remove(2)
x = a.pop(0)
print(x, a)

Natija:

1 [2, 3]

remove(2) birinchi 2 ni o'chirdi → [1, 2, 3]. pop(0) esa 1 ni sug'urib oldi.
