01

Ma’lumotlar tuzilmasi nima?

Xotirada tartibli saqlash va tezkor qayta ishlash poydevori

1-qism: Ma'lumotlar tuzilmalari tushunchasi.

Python'ning 5 ta asosiy tuzilmasi

1. String (str)

Belgilar ketma-ketligi, matnlar. O'zgarmas (immutable): "Backend".

2. List (ro'yxat)

Tartiblangan, o'zgaruvchan (mutable) to'plam: [10, 20, 30].

Qolgan 3 ta tuzilma (tuple, set, dict) 5-haftada o'rganiladi.
02

String yaratish usullari

Tirnoqlarning to'g'ri tanlovi va ko'p qatorli matnlar

2-qism: String yaratish.

String yaratishning 3 usuli

# 1. Bittalik tirnoq
shahar = 'Toshkent'

# 2. Qo'shtirnoq (ichida apostrof bo'lganda qulay)
davlat = "O'zbekiston"

# 3. Uchlik tirnoq (ko'p qatorli matnlar)
maqol = """Bilimli kishi
bilmaganini so'raydi,
bilmagan kishi - qo'rqadi."""
Qo'shtirnoq va bittalik tirnoq farqini eslatib o'ting.
03

Immutable (O'zgarmas) String

TypeError va satrlarni xavfsiz boshqarish

3-qism: Immutability tushunchasi.

Immutability va TypeError

Taqiqlangan amal

s = "Python"
s[0] = "J"
# TypeError: 'str' object
# does not support item assignment

To'g'ri usul (Yangi satr)

s = "Python"
s2 = "J" + s[1:]
print(s2)  # Jython
print(s)   # Python (o'zgarmadi!)
Satrning birorta belgisini almashtirish doim yangi satr yaratish orqali bo'ladi.

Tezkor sinov: Natijani toping

Quyidagi kod ishlaganda ekranga nima chiqadi?

word = "Salom"
yangi = "K" + word[1:]
print(yangi)
print(word)

Natija:

Kalom
Salom

Chunki word ning o'zi xotirada o'zgarmay saqlanib qoladi!
