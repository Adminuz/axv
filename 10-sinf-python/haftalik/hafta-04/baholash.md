# 10-sinf (Advanced Python Back-end): 4-hafta baholash qaydnomasi

**Mavzular:**
10. API havfsizligini ta'minlash
11. Tayyor loyihani hostingga joylash (deploy)
12. FastAPI loyiha yaratish. Loyiha uchun MB ni loyihalash va yaratish, dastlabki sozlamalar

Eslatma: dasturda deploy mavzusi «Oraliq nazorat» bilan birga ko'rsatilgan. Shu haftadagi deploy amaliy topshirig'i oraliq nazorat (20 ball) tarkibiga kiritilishi mumkin; yakuniy qaror mentorda.

## Mentor qaydlari va tahlil

- **Darsdagi asosiy yutuqlar:** DRF bobi API xavfsizligi va deploy bilan yakunlandi; o'quvchilar FastAPI bobiga E-Library loyihasi poydevori bilan kirishdi.
- **Keyingi haftaga ko'prik:** 5-haftada FastAPI da foydalanuvchilarni boshqarish (JWT, parol xeshlash, rollar), CRUD amallar (model, forma, validatsiya) o'tiladi. Bugungi `users`, `books` jadvallari va `config` shu uchun kerak bo'ladi.
