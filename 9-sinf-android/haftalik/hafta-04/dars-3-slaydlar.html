01

if-else ifoda sifatida

Ternar operatorsiz, toza va xavfsiz qiymat tanlash

1-qism: if as expression.

if ifoda sifatida (Expression)

An'anaviy if-else

var max = 0
if (a > b) {
    max = a
} else {
    max = b
}

Kotlinda qisqa ifoda

val max = if (a > b) a else b
// Bir qatorda, val bilan xavfsiz!

Kotlinda ternary (?:) operatori o'rniga if ishlatiladi!

if natijasini to'g'ridan-to'g'ri val o'zgaruvchisiga tenglash mumkin.
02

when: Zamonaviy tanlash operatori

Switch o'rnini egallagan kuchli va moslashuvchan mexanizm

2-qism: when operatori.

when operatorining imkoniyatlari

val fasl = 2
when (fasl) {
    1 -> println("Qish")
    2 -> println("Bahor")
    3 -> println("Yoz")
    4 -> println("Kuz")
    else -> println("Noto'g'ri raqam")
}
// break so'zi umuman shart emas!
Java switch'idagi eng katta xato (break'ni unutish) Kotlinda butunlay hal qilingan.

Oraliqlar (Range: in ..)

Baholash shkalasi

val ball = 85
val baho = when (ball) {
    in 90..100 -> "5 (A'lo)"
    in 70..89  -> "4 (Yaxshi)"
    in 60..69  -> "3 (Qoniqarli)"
    else       -> "2 (Qoniqarsiz)"
}
println("Baho: $baho")

Ko'p qiymatlarni birlashtirish

val oy = 5
val kunlar = when (oy) {
    1, 3, 5, 7, 8, 10, 12 -> 31
    4, 6, 9, 11 -> 30
    2 -> 28
    else -> 0
}
in 90..100 sintaksisini va vergul bilan bir nechta qiymat berishni ko'rsating.
03

Amaliyot va Xavfsizlik

To'liq qamrov va else blokining zarurligi

3-qism: else va amaliy dastur.

Svetofor va Tezlik boshqaruvi

val chiroq = "Yashil"
val tezlik = 65

when (chiroq) {
    "Qizil" -> println("TO'XTANG!")
    "Sariq" -> println("DIQQAT!")
    "Yashil" -> {
        if (tezlik > 60) {
            println("Ogohlantirish: Tezlik yuqori ($tezlik km/soat)!")
        } else {
            println("Harakatlanishga ruxsat.")
        }
    }
    else -> println("Noma'lum signal")
}
when ichida blok {} va if-else birga qanday ishlashini ko'rsating.
