02

HTMLga CSS ulash

Uch usul: style atributi, <style> tegi, <link> tegi

2-qism, 8 daqiqa.

CSS ning uch turi

Inline

bosing

Bitta teg ichida, style atributi bilan. Faqat shu elementga ta'sir qiladi.

Internal

bosing

<head> ichidagi <style> tegida. Butun shu sahifaga ta'sir qiladi.

External

bosing

Alohida .css fayl, <link> bilan ulanadi. Ko'p sahifaga bitta fayl.

Kartalarni bosdiring. Savol: «Sizcha, 50 sahifali saytda qaysi usul qulay?»

Uch usul kodda

1. Inline: style atributi


<h1 style="color: red;">Salom</h1>

Tez sinash uchun qulay, lekin takrorlanadi va kodni chalkashtiradi.

2. Internal: style tegi


<head>
  <style>
    h1 { color: red; }
  </style>
</head>

Bitta sahifa uchun yetarli.

3. External: link tegi


<head>
  <link rel="stylesheet" href="style.css">
</head>

style.css ichida faqat CSS yoziladi: h1 { color: red; }

«Keyingi» tugmasi bilan uch usulni ketma-ket ko'rsating. External faylda <style> tegi YOZILMAYDI, faqat qoidalar.

External CSS: bitta fayl, ko'p sahifa

Rangni bitta joyda o'zgartirsangiz, butun sayt o'zgaradi.
Professional loyihalarda asosiy usul: external. Kelgusida Bootstrap ham aynan shunday ulanadi.

Mini-test

External CSS faylini HTMLga qaysi teg ulaydi?

To'g'ri: <link> teg <head> ichida, rel="stylesheet" va href bilan yoziladi.
Javobni o'quvchilar aytib bo'lgach bosing.

Chapda CSS, o'ngda HTML. Class: bir nechta elementda takrorlansa bo'ladi. Id: sahifada faqat bitta.

Class yoki id?

Class

  • Nuqta bilan: .karta
  • Ko'p elementda takrorlanadi
  • Bitta elementda bir nechta: class="karta katta"
Ko'pincha shu ishlatiladi

Id

  • Panjara bilan: #logo
  • Sahifada faqat bir marta
  • Yagona, noyob element uchun
Bir id ikki marta yozilmaydi
O'xshatish: class sinfdagi «a'lochilar guruhi», id esa pasportdagi noyob raqam. Guruhga ko'pchilik kiradi, raqam esa bittada.

04

Ustuvorlik

Ikki qoida bir elementga to'qnashsa, qaysi biri yutadi?

4-qism, 5 daqiqa. CSS priority va specificity.

Specificity: kim kuchliroq?

Ballar hisoblash uchun oddiy o'xshatish. Teng bo'lsa, oxirgi yozilgani yutadi.

Raqamlar eslab qolish uchun soddalashtirilgan model: element 1, class 10, id 100, style atributi 1000. Teng kuchda oxirgi yozilgan qoida yutadi (cascade).

Matn qaysi rangda?


p { color: red; }
.xabar { color: green; }
#asosiy { color: blue; }
    

<p id="asosiy" class="xabar">
  Salom!
</p>

Abzats matni qaysi rangda ko'rinadi?

Id (100) > class (10) > element (1). Eng kuchlisi yutadi, qoida tartibining ahamiyati yo'q.
Avval o'quvchilar o'ylasin, keyin bosing. Ko'p bola «oxirgisi» deb adashadi: oxirgi faqat TENG kuchda yutadi.

Odatiy xatolar

color: red dan keyingi e'lon ishlamay qolishi mumkin. Har doim ;

Fayl ulanmagan

href yo'li noto'g'ri yoki rel="stylesheet" yo'q: stil chiqmaydi

Stil ishlamasa: 1) fayl nomi va yo'l, 2) nuqta/panjara, 3) figurali qavs yopilganmi, 4) boshqa kuchliroq qoida yo'qmi. Brauzerda F12 orqali ko'rish mumkin.
