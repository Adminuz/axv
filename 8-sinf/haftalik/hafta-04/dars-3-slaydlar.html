Takrorlash

border va background-color meros bo'lmaydi — har bir elementda alohida yozish kerak.
O'tgan darsdan (rang, shrift, meros) 5 daqiqa takrorlash. Keyin box model ga o'tamiz.

Brauzer uchun har bir element — quti

O'xshatish: sovg'a qutisi. Sovg'a — content, yumshoq qog'oz — padding, quti devori — border, javondagi bo'sh joy — margin.

Padding va Margin farqi

Padding

  • Chegara ichida
  • Fon rangi padding ni qoplaydi
  • Element ko'rinadigan hajmini kattalashtiradi
.karta {
  padding: 20px;
  background: lightblue;
}
≠

Margin

  • Chegaradan tashqarida
  • Fon rangi yo'q, shaffof
  • Boshqa elementlarga masofa beradi
.karta {
  margin: 15px;
  /* fon yo'q */
}
Katta xato: o'quvchilar padding ni margin bilan, yoki aksincha, adashtiradi. DevTools da ko'rsating.

Qisqa yozuv (shorthand)

/* 1 qiymat — to'rt tomon */
padding: 10px;

/* 2 qiymat — tepa/past | chap/o'ng */
padding: 10px 20px;

/* 3 qiymat — tepa | chap/o'ng | past */
padding: 10px 20px 5px;

/* 4 qiymat — tepa, o'ng, past, chap (soat mili bo'yicha) */
padding: 10px 20px 5px 0;

/* Alohida tomon */
margin-top: 30px;
margin-left: 0;

/* Gorizontal markazlash (width bilan birga!) */
margin: 0 auto;
«Soat mili bo'yicha» — Top, Right, Bottom, Left — «TRouBLe» (muammo) deb ham eslab qolishadi.

Border — chegara chizig'i

/* qalinlik   tur      rang */
border: 3px  solid  crimson;

border-radius: 12px;             /* yumaloq burchaklar */
border-bottom: 1px dashed gray;  /* faqat bitta tomon */
border-top: none;                /* chegara yo'q */

Nuqtali · · ·

border-radius bilan kartalar va tugmalar yaratamiz. Agar qalinlik, tur yoki rang bo'lmasa — chegara ko'rinmaydi.

box-sizing muammosi

content-box (standart)

width: 300px;
padding: 20px;
border: 2px solid;

Jami kenglik:
300 + 40 + 4 = 344px

Kutilganidan kattaroq!

→

border-box (tavsiya)

* { box-sizing: border-box; }
width: 300px;
padding: 20px;
border: 2px solid;

Jami kenglik: 300px

Padding va border ichiga sig'adi!

Deyarli har bir loyihada * { box-sizing: border-box; } yoziladi

Bu keng tarqalgan muammo. DevTools da element hajmini ko'rsating va box-sizing qo'shganda qanday o'zgarishini ko'rsating.

DevTools da Box model

F12 → Elements

  • Elementni tanla
  • Computed ↗ bo'limida rangli quti ko'rinadi
  • To'q yashil — content
  • Ko'k — padding
  • Sariq — margin
  • To'q sariq — border

Nima ko'ramiz?

  • Content: 200 × 100
  • Padding: har tomonda
  • Border: qatlam qalinligi
  • Margin: masofa

Real vaqtda o'zgartirish mumkin!

Proyektorda F12 ni oching va to'g'ridan to'g'ri ko'rsating. O'quvchilar ham o'z kompyuterlarida takrorlasin.

Amaliyot: Karta (.karta) yasaymiz

/* CSS */
* { box-sizing: border-box; margin: 0; padding: 0; }

.karta {
  width: 300px;
  padding: 20px;
  border: 2px solid royalblue;
  border-radius: 12px;
  margin: 15px;
  background-color: white;
}
<!-- HTML -->
<div class="karta">
  <h3>Birinchi karta</h3>
  <p>Bu karta matni.</p>
</div>
<div class="karta">
  <h3>Ikkinchi karta</h3>
  <p>Bu karta matni.</p>
</div>
O'quvchilar o'z karta dizaynini yaratishadi. Rasm qo'shish, border-radius, hover effekti — bonus.

Odatiy xatolar

padding ↔ margin adashtirish

padding — ichki, margin — tashqi. DevTools da tekshiring.

box-sizing yozmaslik

Quti kutilganidan 344px chiqishi sababchisi shu.

margin: 0 auto bilan width yo'q

Markazlash ishlaydi faqat width berilganda.

border da tur tushib qolishi

border: 2px crimson — solid yo'q, chegara ko'rinmaydi.

Har bir xatoni amalda ko'rsating — o'quvchilar yozib qolsin.

Tezkor nazorat

Box model qismlarini ichkaridan tashqariga ayting

Javob: content → padding → border → margin

padding: 10px 20px; nimani anglatadi?

Javob: tepa/past 10px, chap/o'ng 20px

box-sizing: border-box nima beradi?

Javob: width padding va border ni o'z ichiga oladi

margin: 0 auto; nima uchun?

Javob: width berilgan blokni gorizontal markazlash
