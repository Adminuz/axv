# 1-dars. UX va UI dizayn tushunchalari: nima va nima uchun

**Hafta:** 1 · **Davomiyligi:** 80 daqiqa · **Turi:** nazariya + amaliyot (qog'ozda) · **I-bob**, 1-dars

> Dasturda «UX va UI dizayn tushunchalari» mavzusiga 2 dars ajratilgan (1–2). Bo'linish: 1-dars — UX nima, UI nima, farqi, dizaynerlar qayerda ishlaydi va nega muhim; 2-dars — UX/UI tamoyillari (4C, UX tamoyillari), yaxshi va yomon dizayn, wireframe / mockup / prototip bosqichlari. 3-dars — foydalanuvchi tadqiqoti.
> Manba: o'quv qo'llanma, 1.1-bo'lim («UX va UI dizayn tushunchalari»), 1.1-jadval. Dars birinchi bo'lgani uchun kurs xaritasi bilan tanishtirish ham bor.

## 1. Dars rejasi

**Maqsad:** o'quvchi UX va UI nima ekanini o'z so'zi bilan tushuntiradi, ikkalasini farqlaydi va real ilovadan misol bilan ko'rsatadi.

**Kutiladigan natija:**
- UX (User Experience) — foydalanuvchi tajribasi, UI (User Interface) — foydalanuvchi interfeysi ekanini biladi.
- Jadval bo'yicha farqni (tashqi ko'rinish va umumiy tajriba) ayta oladi.
- UX dizayner va UI dizaynerning asosiy ishlarini sanaydi.
- UX/UI dizayn qayerlarda qo'llanishini (veb-sayt, mobil ilova, dashboard, aqlli qurilma) biladi.
- Yaxshi UX/UI nega kerakligini (mamnunlik, raqobat, brendga ishonch) tushuntiradi.

| Vaqt | Bosqich | Mazmun |
|---|---|---|
| 0–10 | Kirish | Tanishuv, kurs xaritasi, «sizni eng ko'p g'azablantirgan ilova» savoli |
| 10–25 | Yangi mavzu 1 | UX nima, UX dizayner nima qiladi |
| 25–35 | Yangi mavzu 2 | UI nima, UI dizayner nima qiladi |
| 35–40 | Tanaffus | |
| 40–52 | Yangi mavzu 3 | Farq, o'zaro bog'liqlik, qayerda ishlanadi, nega muhim |
| 52–75 | Amaliyot | Telegram/Instagram tahlili va qog'ozda dizayn |

## 2. Konspekt

### 2.1. Kirish (10 daqiqa)
Birinchi dars: tanishuv va kurs xaritasi (nazariya → wireframe → Figma va boshqa vositalar → HTML/CSS/JS → React). Keyin savol: «Qaysi ilova yoki sayt sizni g'azablantirgan? Nega?» 3–4 o'quvchi javob beradi. Ularning javoblari («tugma topolmadim», «juda sekin», «hamma narsa chalkash») bugungi mavzuning o'zi ekanini ayting: «Siz hozir UX muammolarini sanadingiz».

### 2.2. UX nima? (15 daqiqa)
**UX (User Experience) — foydalanuvchi tajribasi.** Qo'llanma ta'rifi: foydalanuvchining interfeys bilan ishlash tajribasi va taassuroti. U maqsadiga erisha oladimi va buni bajarish qanchalik oddiy yoki murakkab ekanini belgilaydi.

O'xshatish — **eshik**: chiroyli eshik, lekin «tortish» kerakmi yoki «itarish»? Odam eshik oldida turib qolsa, bu UX muammosi (eshik chiroyli bo'lsa ham).

UX savoli: **«Bu mahsulot foydalanuvchi uchun qanchalik qulay?»**

UX dizayner (qo'llanma bo'yicha):
- foydalanuvchi muammolarini o'rganadi va yechim topadi;
- interfeys qulayligini ta'minlaydi;
- sketch, wireframe va prototiplar yaratadi;
- mahsulotni test qiladi va doimiy takomillashtirib boradi.

UX ning o'lchovlari: qulaylik, tezlik, hissiy tajriba (jadvaldan). Misol: Telegramda xabar yuborish 2 bosishda bo'ladi. Bu yaxshi UX. Davlat xizmati saytida bitta ma'lumot uchun 7 sahifa ochish — yomon UX.

Eslatma: UX faqat ekranga tegishli emas. Buyurtma kutish vaqti, qo'ng'iroq markazi, o'ramning ochilishi ham tajribaga kiradi. Biz kursda raqamli mahsulotga e'tibor beramiz.

### 2.3. UI nima? (10 daqiqa)
**UI (User Interface) — foydalanuvchi interfeysi:** mahsulotning qanday ko'rinishi va qanday tuzilishi. Qo'llanma misoli: Google Maps ochganda ko'rgan xarita, tugmalar va menyular. Yaxshi UI da hamma elementlar uyg'un va o'zaro bog'liq bo'ladi.

UI dizayner (qo'llanma bo'yicha):
- ranglar bilan ishlaydi;
- to'g'ri shriftlarni tanlaydi;
- ikonlar va grafik elementlarni ishlab chiqadi;
- vizual dizaynning umumiy uyg'unligini yaratadi.

UI savoli: **«Bu mahsulot qanday ko'rinadi va chiroylimi?»** Foydalanuvchi ko'zi bilan ko'radigan hamma narsa — UI.

UI elementlariga misollar: tugma (button), menyu, matn maydoni (input), ikon, rasm, rang va shrift.

### 2.4. UX va UI farqi (jadval) va o'zaro bog'liqlik (12 daqiqa)

| UI dizayn | UX dizayn |
|---|---|
| Tashqi ko'rinishni tayyorlaydi | Umumiy tajribani shakllantiradi |
| Ranglar, tugmalar, shriftlar | Qulaylik, tezlik, hissiy tajriba |
| Ko'zga ko'rinadigan qismlar | Foydalanuvchining ichki his-tuyg'ulari |

O'xshatishlar:
- **Restoran:** UX — kutish vaqti, menyuni tushunish, xizmat; UI — idish, bezak, taom ko'rinishi.
- **Uy:** UX — xonalar joylashuvi va eshiklar qulayligi; UI — rang, mebel, parda.
- **Avtomobil:** UX — haydash qulayligi; UI — dashbord, tugmalar ko'rinishi.

Muhim xulosa: **ikkalasi ham kerak va bir-birini to'ldiradi.**
- Chiroyli UI + yomon UX = chiroyli, lekin foydalanib bo'lmaydigan ilova (ko'rinishi yaxshi, lekin to'lov tugmasi topilmaydi).
- Yaxshi UX + yomon UI = ishlaydi, lekin ishonch uyg'otmaydi (chalkash ranglar, o'qib bo'lmaydigan shrift).
- Yaxshi UX + yaxshi UI = foydalanuvchi mamnun, qaytib keladi.

**Odatiy xato:** «UX = chiroyli dizayn». Yo'q: chiroylilik UI qismi, UX undan kengroq.

### 2.5. Dizaynerlar qayerda ishlaydi? (qisqa, 12-daqiqa ichida)
Qo'llanma bo'yicha UX/UI sohasi shu mahsulotlar dizayni va prototipini yaratadi:
- veb-saytlar;
- mobil ilovalar;
- internet platformalar;
- dashboardlar (ma'lumot paneli);
- aqlli qurilmalar;
- boshqa IT-mahsulotlar.

O'quvchi hayotidan: Telegram, Instagram, o'yinlar, maktab elektron jurnali, Click/Payme kabi ilovalar, aqlli soat. Hamma narsa kimdir dizayn qilgan.

### 2.6. Nega bu muhim?
Qo'llanma xulosasi: samarali UI/UX foydalanuvchi mamnunligini oshiradi, mahsulotning raqobatbardoshligini ta'minlaydi va brendga bo'lgan ishonchni mustahkamlaydi. Oddiy tilda: qulay ilova qoladi, qulay bo'lmasini o'chirib tashlashadi (telefondan ham, xotiradan ham). Bu — dizayner kasbiga talab borligining sababi.

Eslatma mentorga: aniq ish haqi, bozor statistikasi qo'llanmada yo'q, shuning uchun slaydlarda raqam keltirilmagan. Xohlasangiz mahalliy ish e'lonlaridan o'zingiz misol qo'shing.

## 3. Misollar (kod o'rniga)

Bu darsda kod yo'q. O'rniga ikkita **qog'ozdagi eskiz namunasi**: bir xil UX (bir xil qadamlar), turli UI.

**Namuna: kirish (login) ekrani, UX bir xil: «telefon raqam → Kirish» (2 qadam).**
- Variant A (UI): to'q fon, katta ko'k tugma, yumaloq burchaklar.
- Variant B (UI): oq fon, yashil tugma, to'g'ri burchaklar.
UX o'zgarmadi (qadamlar bir xil), UI o'zgardi (ko'rinish).

**Namuna: UX ni o'zgartirish.** Variant C: telefon raqam + ism + parol + parolni takrorlash + yosh + shahar → Kirish (6 maydon). UI chiroyli bo'lishi mumkin, lekin UX yomonlashdi.

## 4. Amaliy topshiriqlar

Material: A4 qog'oz, qalam, rangli qalamlar. Kompyuter ixtiyoriy (Figma bepul onlayn, ro'yxatdan o'tishni talab qiladi: mentor hal qiladi; bugun majburiy emas).

### Oson — UX yoki UI?
Ro'yxatdagi har bir gapni UX yoki UI ga ajrating: (1) tugma rangi ko'k; (2) to'lov 2 bosishda bajariladi; (3) shrift «Roboto»; (4) sahifa 1 soniyada ochiladi; (5) ikonlar bir xil uslubda; (6) yangi foydalanuvchi qayerga bosishni tushunadi.
**Kutiladigan natija:** to'g'ri ajratilgan 6 ta gap.
**Yechim:** (1) UI; (2) UX; (3) UI; (4) UX (tezlik); (5) UI; (6) UX. Eslatma: 4 va 6 ko'rinmaydi, lekin tajribaga ta'sir qiladi. Ba'zi gaplar (masalan, tugma o'lchami) ikkala tomonga ham tegishli bo'lishi mumkin: bahsni rag'batlantiring, mantiqiy asos bo'lsa qabul qiling.

### O'rta — Ilova tahlili
Telegram, Instagram yoki sevimli o'yinni tanlang. Jadval to'ldiring: 2 ta yaxshi UX nuqtasi, 1 ta yomon UX nuqtasi, 2 ta UI element (rang, shrift, ikon) va ular nima uchun mos tushgani.
**Kutiladigan natija:** to'ldirilgan jadval (daftar yoki skrinshot bilan).
**Yechim namunasi (Telegram):**
| | Misol |
|---|---|
| Yaxshi UX | Xabar yuborish 1 tugma; yozishmalar tez qidiriladi |
| Yomon UX | Sozlamalar ko'p bo'limli, kerakli narsani topish qiyin (o'quvchi fikri bo'lishi mumkin) |
| UI | Ko'k asosiy rang va oq fon: sokin, ishonchli; yumaloq avatarlar |
Aniq javob o'quvchi tanlovga bog'liq: mezon — tanlov asoslangan bo'lsa bo'ldi.

### Qiyin — Bir UX, ikki UI
Maktab oshxonasi uchun «Buyurtma» ekranini qog'ozda 2 xil UI da chizing (telefon ramkasi). Qadamlar bir xil: taom tanlash → miqdor → «Buyurtma berish». Birida rang va shakl bir uslubda, ikkinchisi butunlay boshqa uslubda. Pastda: nima o'zgardi (UI), nima o'zgarmadi (UX)?
**Kutiladigan natija:** 2 ta eskiz va 2–3 jumlalik izoh.
**Yechim:** UI farqi: rang, shrift, tugma shakli, ikonlar. UX bir xil: qadamlar soni va tartibi. Kuchli o'quvchi uchun: UX ni ham yaxshilash (masalan, «Oxirgi buyurtmani takrorlash» tugmasi).

### Bonus
UX/UI dizayner ish e'loni (hh.uz, LinkedIn yoki Telegram kanal) toping. Qaysi talablar UX ga, qaysilari UI ga tegishli? **Yechim:** UX: tadqiqot, wireframe, test; UI: rang, tipografiya, dizayn tizimi, Figma. Haqiqiy e'lon bo'yicha tekshiring.

## 5. Tezkor nazorat
1. UX ning to'liq nomi va ma'nosi? *(User Experience, foydalanuvchi tajribasi.)*
2. UI ning to'liq nomi va ma'nosi? *(User Interface, foydalanuvchi interfeysi: ko'rinish va tuzilma.)*
3. «Tugma rangi» UX ga tegishlimi yoki UI ga? *(UI.)*
4. Chiroyli lekin foydalanib bo'lmaydigan ilova qaysi qismi yomon? *(UX.)*
5. UX/UI dizayner qanday mahsulotlar bilan ishlaydi? *(Veb-sayt, mobil ilova, dashboard, aqlli qurilma...)*
6. Yaxshi UX/UI biznesga nima beradi? *(Mamnunlik, raqobatbardoshlik, brendga ishonch.)*

## 6. Uyga vazifa
`uyga-vazifa.md` dagi 1-topshiriq (hafta uchun umumiy fayl, boshqa agent tayyorlaydi). Taklif: «O'zingiz kunda foydalanadigan 1 ta ilovada 1 ta yaxshi va 1 ta yomon UX nuqtasini toping, skrinshot yoki tavsif bilan» (20–25 daqiqa).

## 7. Mentor uchun eslatmalar
- Birinchi dars: o'quvchilar bir-birini tanimasligi mumkin, 2–3 daqiqa tanishuv qo'shing.
- Talab qilinadigan dastur yo'q; Figma keyingi hafta/bobda. Ro'yxatdan o'tish talab qilinsa, mentor oldindan tayyorlasin.
- 2-darsga ko'prik: «Yaxshi UX ni nima yaratadi? Qaysi qoidalar bor? Bu 2-darsda».
