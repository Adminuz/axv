# 16-dars. Figma platformasi: imkoniyatlari, afzalliklari va ish muhiti

> Oldingi haftada Figma'da birinchi elementlarni chizdik. Bugun uni professional tartibda ishlatishni o'rganamiz: fayl tuzilmasi, qurilmada ko'rish va vektor ikonka.

## Dars xulosasi

- Figma — bulutdagi hamkorlik dizayn platformasi.
- Afzalliklari: bulut, real vaqt, kross-platforma.
- Ierarxiya: Project → File → Page → Frame → Layer.
- Qatlamlarga ma'noli nom beriladi.
- Vektor grafika kattalashganda aniq; ikonka uchun SVG.
- Dizaynni Present yoki telefon ilovasida ko'rish mumkin.

## Qo'shimcha ma'lumot

### Community
Bepul shablon va UI kitlar kutubxonasi.

### Plugin
Figma'ga qo'shimcha imkoniyat.

### Present
Dizaynni to'liq ekranda ko'rsatish.

### FigJam
Figma'ning fikrlar doskasi.

## Atamalar lug'ati

| Atama | Ma'nosi |
|---|---|
| Figma | Bulutdagi dizayn platformasi |
| File | Figma fayli |
| Page | Fayl sahifasi |
| Frame | Dizayn ekrani |
| Layer | Qatlam |
| Vektor | Formulali grafika |
| SVG | Vektor fayl formati |
| Export | Fayl qilib saqlash |

## Bilasizmi?

- Figma'da mijoz brauzerda havola orqali dizaynni ko'ra oladi va sharh yoza oladi.
- Tesla Model 3 boshqaruv paneli prototipi Figma'da yaratilgan mashhur misol (uslubiy ko'rsatmadan).
- Figma Community'da minglab bepul shablon va UI kitlar bor.

## Topshiriqlar

### 1. Figma nima · oson

Figma nima uchun ishlatiladi?

**Kutiladigan natija:** Interfeys dizayni va prototip.

### 2. Afzallik · oson

Figma'ning bir afzalligini yozing.

**Kutiladigan natija:** Masalan, bulutda ishlashi.

### 3. Frame · oson

Frame nima?

**Kutiladigan natija:** Dizayn ekrani.

### 4. Tezkor tugma · oson

Frame va Matn uchun tugmalar?

**Kutiladigan natija:** `F` va `T`.

### 5. Ierarxiya · o'rta

Fayl ierarxiyasini tartib bilan yozing.

**Kutiladigan natija:** Project, File, Page, Frame, Layer.

### 6. Nomlash · o'rta

3 ta qatlamga ma'noli nom bering.

**Kutiladigan natija:** Header, Qidiruv, Savat.

### 7. Vektor/rastr · o'rta

Vektor va rastr farqini yozing.

**Kutiladigan natija:** Vektor aniq, rastr xiralashadi.

### 8. Eksport · o'rta

Ikonka uchun qaysi format?

**Kutiladigan natija:** SVG.

### 9. Ikonka chizish · qiyin

Qidiruv ikonkasi qaysi shakllardan tuziladi?

**Kutiladigan natija:** Aylana va chiziq.

### 10. Sahifalar · qiyin

Sahifalarga nima uchun bo'linadi?

**Kutiladigan natija:** Tartib va tez topish.

### 11. Qurilmada ko'rish · qiyin

Dizaynni telefonda qanday ko'rasiz?

**Kutiladigan natija:** Present yoki Figma ilovasi.

### 12. Ikonkalar to'plami · bonus

6 ta ikonkadan to'plam chizing.

**Kutiladigan natija:** Bir xil uslubdagi 6 SVG.
