# 18-dars. Jamoaviy ishlash va Dev Mode: sharh, versiya tarixi va dizaynni dasturchiga topshirish

> Dizayn tayyor bo'lgach, u jamoa va dasturchiga yetib borishi kerak. Bugun ulashish, sharh qoldirish va Dev Mode orqali dizaynni kodga o'tkazishni o'rganamiz.

## Dars xulosasi

- Figma — jamoa uchun yagona muhit.
- Ruxsat: Can view va Can edit; eng kam ruxsat qoidasi.
- Sharh: aniq, muloyim, taklif bilan; hal bo'lsa Resolve.
- Muhim bosqichda nomli versiya saqlang.
- Dev Mode: o'lcham, masofa, rang, CSS va eksport.
- Figma kodi — boshlang'ich nuqta; loyiha qoidalariga moslang.

## Qo'shimcha ma'lumot

### Branching
Fayl nusxasida tajriba qilib, keyin birlashtirish (tarifga qarab).

### Status
Ready for dev belgisi: dizayn tayyor.

### FigJam
Jamoaviy fikrlar doskasi.

### Plugin
Handoff uchun qo'shimchalar.

## Atamalar lug'ati

| Atama | Ma'nosi |
|---|---|
| Share | Ulashish |
| Can view | Faqat ko'rish ruxsati |
| Can edit | Tahrirlash ruxsati |
| Comment | Sharh |
| Resolve | Sharhni yopish |
| Version history | Versiya tarixi |
| Dev Mode | Dasturchi ko'rinishi |
| Handoff | Dizaynni topshirish |

## Bilasizmi?

- Alt tugmasini bosib turib, elementlar orasidagi masofani piksellarda ko'rish mumkin.
- Dev Mode'da komponent hujjatlari va kod havolalarini biriktirish mumkin.
- Katta jamoalarda dizayn va kod izchil bo'lishi uchun dizayn tokenlari ishlatiladi.

## Topshiriqlar

### 1. Share · oson

Share tugmasi nima qiladi?

**Kutiladigan natija:** Faylni ulashadi.

### 2. Ruxsatlar · oson

Ikki ruxsat darajasini yozing.

**Kutiladigan natija:** Can view va Can edit.

### 3. Sharh · oson

Sharh qoldirish tugmasi?

**Kutiladigan natija:** `C`.

### 4. Dev Mode tugmasi · oson

Dev Mode ni qaysi tugma ochadi?

**Kutiladigan natija:** `Shift+D`.

### 5. Eng kam ruxsat · o'rta

Eng kam ruxsat qoidasini tushuntiring.

**Kutiladigan natija:** Faqat kerakli ruxsat.

### 6. Resolve · o'rta

Resolve nima qiladi?

**Kutiladigan natija:** Hal bo'lgan sharhni yopadi.

### 7. Versiya · o'rta

Versiyani nom bilan nima uchun saqlaymiz?

**Kutiladigan natija:** Keyin qaytish oson.

### 8. Dev Mode qiymatlari · o'rta

Dev Mode da qanday 4 qiymat bor?

**Kutiladigan natija:** O'lcham, masofa, rang, shrift.

### 9. CSS moslash · qiyin

`width: 280px` ni responsiv qiling.

**Kutiladigan natija:** `max-width: 17.5rem`.

### 10. Handoff ro'yxati · qiyin

5 ta handoff tekshiruvini yozing.

**Kutiladigan natija:** Nomlar, komponent, tizim, assets, holatlar.

### 11. Sharh sifati · qiyin

Yomon sharhni yaxshiga aylantiring.

**Kutiladigan natija:** Aniq va taklif bilan.

### 12. Jamoaviy loyiha · bonus

Juftlikda bir-biringiz dizaynini ko'rib chiqing.

**Kutiladigan natija:** 2 sharh va 1 taklif.

## O'zingizni tekshiring

1. Ruxsat darajalari?
2. Sharh qoidasi?
3. Versiya tarixi nima?
4. Dev Mode nima beradi?
5. Figma kodiga munosabat?
6. Handoff ro'yxati?

## Uyga vazifa

Dizaynni juftlikda ulashing, sharh qoldiring va handoff qiymatlarini CSS ga o'tkazing (30–40 daqiqa). To'liq shart: `uyga-vazifa.md`.
